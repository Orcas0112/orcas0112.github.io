# Twilight Bazaar — Variant Era progress

**V9.2 delivers all six variants together:** Shiny, Shadow, Glitched, Golden, Prismatic and Ascended. Five types can come from existing packs as independent rolls. All six have Forge routes. Shiny keeps unique alternate-color palettes; Golden is a distinct metallic-gold variant. Original Mysticals stay protected from fusion, but can earn their Ascended appearance through an endgame Forge challenge.

**Possible later updates (not implemented in V9.2):** Fix missing original Blook image links where trustworthy licensed sources can be found; refine individual alternate color palettes; add player-curated showcases, wishlists, variant-safe local simulated trading, and optional profile cosmetics. No new custom packs, Bingo, or Blook Hunts without explicit request.
