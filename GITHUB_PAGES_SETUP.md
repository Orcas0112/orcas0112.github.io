# Install Twilight Bazaar V9.1.1 on GitHub Pages

Your site: https://orcas0112.github.io/
Your repo: https://github.com/orcas0112/orcas0112.github.io

1. Export a save backup inside the current game (Vault & Settings).
2. Extract the V9.1 ZIP. Upload all individual files (including the hidden `.nojekyll`) into the repository root, not a subfolder.
3. Commit changes on `main`; leave Settings → Pages at **main / (root)**.
4. Reload the website, hard refreshing if needed. The header should display **V9.1.1 SHINY SURGE**.
5. Open a regular pack or click **Shiny Forge**. Shiny pack chance is 0.9% per individual draw. Existing OG Blook odds are unchanged.

Do NOT wipe the repository, reset your collection, or delete your saves. Unknown/retired historic art URLs may still fail; the Image Checker reports these. The admin password is an in-browser gate, not secure remote administration.
