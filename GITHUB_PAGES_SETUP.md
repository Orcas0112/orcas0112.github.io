# Publishing V9.0.4 to GitHub Pages

1. Go to https://github.com/orcas0112/orcas0112.github.io
2. Make sure you're on **main**, then choose **Add file → Upload files**.
3. Unzip the release. Select the **individual files inside** (including `.nojekyll` if present), not the ZIP itself.
4. Commit changes. Existing files with matching names are replaced; you don't need to delete older files manually.
5. Your URL remains https://orcas0112.github.io/ — wait for publishing then hard-refresh.
6. Check **V9.0.4** in the site header; verify the Pack Wall and Fusion Lab.

Export your existing save first. The website is static; the admin password is visible in public JavaScript and is **not** a secure administrative account.
